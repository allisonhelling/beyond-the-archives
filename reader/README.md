# archives unfolded

An independent, browser-based EPUB reader in the same repository as the organizer. No organizer account is required. The organizer web interface is unchanged.

## Run Locally

Requires Node.js 22.13+ (22.x) or 24+ and the full repository checkout. From this folder:

```sh
npm ci --prefix ..
npm ci
npm run dev
```

Open http://127.0.0.1:5174. Local development includes the organizer’s shared **Local Preview** toolbar with matching typography, colors, and compact buttons: switch between Desktop and Mobile, choose a device preset (iPhone 16 by default), or enter dimensions in inches or millimeters under **Preview Size**. Save edits before first entering Mobile, which reloads the reader in an embedded viewport. Later switches keep that frame mounted. The Mobile button shows only the unit selected under Preview Size. That panel uses organizer colors and typography with Width, Height, and Units fields on one row, with Units sized to its longest option and the panel fitted around the controls. Its inner border sits close to the dimension readout and matches the outer border weight; Apply Preview Size sits directly below the inner box. The toolbar is omitted from production builds and embedded previews. The development server does not install the offline shell. To use or test the PWA:

```sh
npm run build
npm run preview
```

Open http://127.0.0.1:4174 while online, wait for **Reader prepared for offline use**, and import EPUBs. After preparation, reopen this same origin offline. Different ports, browsers, profiles, and installed applications can have separate storage. Deploy the built `dist` directory at the root of its own HTTPS origin; native packaging is out of scope.

## Connect To The Local Organizer

For local use, set `VITE_READER_URL=http://127.0.0.1:5174/` in the organizer’s root `.env.local` and `VITE_ORGANIZER_URL=http://127.0.0.1:5173/` in this folder’s `.env.local`. Give both apps the same public Supabase configuration and restart their dev servers. Run the reader with `npm run dev`, sign in, and choose **Open Reader** from organizer settings or Offline. Local Auth redirects must allow the reader origin.

For local organizer sync and reader-account testing, set `VITE_SUPABASE_URL` and `VITE_SUPABASE_PUBLISHABLE_KEY` in this folder’s untracked `.env.local` to the same public values as the organizer and restart the reader. Organizer sync requires this matching account backend; guest reading needs no account. The local Supabase configuration allows reader sign-in redirects at ports 5174 and 4174; restart the local Supabase stack after changing its Auth configuration. Create an account and confirm its email, or use an existing organizer account in the same local project; invitations remain supported. Local browser storage stays separate from the hosted reader’s origin. Keep `127.0.0.1` consistent rather than switching to `localhost`.

## Hosting

Deploy the reader as its own Vercel project using Root Directory `reader`, with **Include source files outside of the Root Directory in the Build Step** enabled. The checked-in reader configuration installs both dependency sets and builds `dist`. See the [deployment guide](docs/IMPLEMENTATION.md#vercel-deployment) for exact settings and troubleshooting.

## Reading

Web links in EPUB text are clickable, including plain URLs such as **URL: https://archiveofourown.org/works/23818510** and addresses beginning with `www.`. They open in a new tab while your book stays open. This also works for books already downloaded.

Import AO3-generated or ordinary reflowable EPUB 2/3 files. Search saved titles, authors, fandoms, tags, summaries, series, collections, publisher, or AO3 work ID. Metadata search and the Fandoms multi-select stay visible on the collapsed toolbar. The **Filters** button opens the filter box; **Hide** closes it without clearing selections. Basic expanded filters cover reading status, author, rating, and organizer collection. Expand **More Metadata Filters**, **Length & Popularity**, and **Publication & File Dates** for:

- Publisher (first in More Metadata Filters), publication status, category, language, archive warnings, relationships, characters, freeform tags, series, active/retained EPUB version, and single/multiple fandoms.
- Excluding freeform tags, warnings, characters, or relationships.
- Minimum/maximum words, published chapters, kudos, bookmarks, comments, and hits.
- Inclusive date ranges for original publication, story update, EPUB packaging, and local import.

Every filter combines with search, other fields, exclusions, and ranges. Fandoms, characters, relationships, and freeform tags use searchable dropdown multi-selects, with selected values shown as removable chips. Language has a dropdown multi-select without a search box. Fandoms and languages default to matching any selected value; characters, relationships, and freeform tags default to requiring all selected values. Searchable fields show a **Match All Selected / Any Selected** control when multiple values are selected. Exclusions reject a book matching any excluded value. Other categorical controls select one saved value. Options show local work counts and offer **Unknown / Not Saved** when applicable. Unknown numeric/date values do not match an active range, including a zero minimum. Applied filters appear as removable chips below the filter box, including search, exclusions, matching modes, and range bounds. They remain visible when the box is hidden. Remove a chip to clear just that value, or use **Clear All Filters** to reset search and filters while preserving sort order. Sort by title, import time, length, popularity, or publication/update/package date. The bookshelf displays 24 works per page. Use Prev, Next, or enter a page number in the centered **Page [ ] of #** control on the Sort By row (wrapping on narrow screens) and press Enter. Search and filters cover the entire saved catalog and return to page one when changed; opening and closing a book preserves the current shelf page. The six Length & Popularity ranges share one compact row; the four Publication & File Dates boxes share another. Both rows scroll horizontally on narrow screens. **EPUB Version** selects the active copy opened by organizer links or other saved downloads retained for the same story. **Packaged** sorts by the creation/download date saved in the EPUB metadata. **Freeform Tags** means AO3 Additional Tags. All Tags defaults to Additional Tags, Relationships, Characters, Categories, then AO3 Warnings. Use the up/down buttons under Tag Format → All Tags Order to change category order. Reader changes save immediately; the organizer uses Save. Tags retain their existing order within each category. Generic Tag and Work Link filters are omitted.

AO3 collections can be included in metadata search but have no dedicated filter; the collection filter uses organizer collections. Software versions, adapter names, duplicate URL/HTML fields, and other downloader diagnostics are not filter controls. This is metadata search, not full-text chapter or personal-note search. Metadata can be older than the online library.

AO3, plain paragraph title pages (including Coil-style conversions), FanFicFare title pages (standard and table formats), standard EPUB package fields, and recognized Calibre custom fields populate the local catalog. Existing downloads are re-indexed locally once when upgrading. **Refresh Local Metadata** re-reads retained files without a network request, changing reading history, or updating organizer data. Fields absent from the EPUB remain unknown; refreshing cannot fetch newer AO3 information.

Choose **One Chapter** or **Entire Work**, independently of **Continuous Scroll** or **Paginated**. Left/Right arrow keys change chapters in both layouts. The chapter/work heading accompanies the top Previous/Next buttons, with its matching EPUB heading moved there to avoid a duplicate. Existing saved settings are preserved. On phones, the header uses icons and omits authors and publication status. Tap reading text to hide or reveal the header/footer. ## Local Storage And Large Libraries

The shelf loads a lightweight metadata catalog; EPUB files, chapter text, and images load for the book you open. Managing notes/status and syncing do not load book contents. Existing reader libraries upgrade automatically, keeping downloads, positions, notes, history, settings, and queued updates. Close older reader tabs if an upgrade is waiting. Metadata refreshes still read retained files one at a time, and a first schema upgrade can take longer for large libraries.

On mobile, the downloaded-work count sits beside Import EPUB. Offline readiness and account/organizer state share a line with a bullet divider, wrapping on very narrow screens. Desktop keeps the existing summary layout.

The shelf summary shows estimated storage used by this reader's site, its browser allowance, and whether persistent storage was granted. Tap the info icon beside browser allowance to learn how to choose EPUB downloads to remove while keeping their reading data. Usage includes the reader's database and offline application cache; it is not an EPUB-only total or a measure of free device space. Unsupported or unavailable browser estimates are shown explicitly. Guest EPUBs stay on this device. Reader accounts upload retained originals to private Supabase storage. Keep original EPUB backups: clearing site data still removes the local library.

**Storage may be cleared automatically** means the browser has not granted persistent storage. It is not a storage-full alert: browsers can clear this site’s local data without advance notice, even while the reader is closed. This can remove EPUBs, personal notes, reading history, positions, preferences, and unsynced cloud/organizer updates across all local guest/account libraries on that reader origin. Already-synced server data and original EPUB files kept outside the browser are unaffected; guest-only or unsynced data may be unrecoverable. **Storage** opens a wide, searchable table for the current library, including downloaded books and cloud entries. Columns show Library, Title, Author, Fandom, Date (import date), Size, Rating, Summary, and Publisher. Click a column heading to sort; click again to reverse its arrow. Drag a heading to reorder columns, or use Alt + Left/Right. Sort and column order are saved. Request Persistent Storage remains available above the table. Persistence depends on the browser and does not protect against manually clearing site data.

If a local save runs out of browser space, the reader reports that the save did not complete and opens **Manage Local Storage**. Select rows or checkboxes, choose **Remove Download**, confirm the selected batch, then retry the failed action. Shift-click selects a range; Select Visible Works selects the current page. Select All selects every work in the current library, including other pages and works hidden by search. Manage Local Storage fills the window; its main scroll moves through the table, with a separate horizontal scroll for wide columns. Choose **Download** for selected cloud entries while signed in and online. **Delete from Cloud**, immediately right of Remove Download, permanently deletes selected EPUB versions and their notes, history, and position from the account across synced devices after confirmation. Guest entries without files are marked Not Downloaded and require reimport. Double-click a row, or press Enter on it, to open work details; closing details returns to the same table search and selection. Nothing is deleted automatically. Remove Download is also available in each downloaded work’s three-dot menu. Removed downloads keep their metadata tiles on the bookshelf, marked Available In Cloud, and remain searchable. Choose Download EPUB on the tile to restore the file: reader accounts download their cloud copy, while guests select the original EPUB. Notes, reading history, and position stay saved; keep an original backup or verify a cloud copy before removing a download. Older saved downloads may show **File size unavailable** until reopened. The site-wide estimate includes guest/account libraries and the offline shell, while this list covers the current library.

There is no book-count cap. Capacity depends on browser storage allowance and device space. Pagination bounds rendered cards, but the metadata catalog and filters still run in memory. The browser suite exercises a synthetic 10,000-entry catalog; this is not a guarantee for 10,000 large EPUBs or every mobile device.

## Limits

- Maximum EPUB: 50 MiB compressed; 16 MiB per extracted resource; 200 MiB extracted resources per import. The reused metadata parser has an additional 2 MiB per-resource / 8 MiB total metadata budget.
- DRM, password-protected ZIPs, fixed layout, interactive books, imported styles/fonts, remote images, and SVG illustrations are unsupported. Unsupported fonts use the reader font. Text, raster images, internal chapter links, summaries, and author notes are supported. Imports reject missing required prose or raster image resources.
- Publication information comes from the imported EPUB snapshot. The existing companion API does not expose a fresh publication metadata snapshot; import a newer EPUB to refresh it. Only reliably mapped AO3 chapter IDs and ordinals can trigger final status or chapter-history synchronization. Uncertain chapters retain local history and do not change organizer progress.
- The reader verifies its own IndexedDB copy. Browser storage can be evicted or cleared; retain original EPUB files. Cloud copies require an invited reader account with reader access; unsynced files remain local.
- The organizer Offline hub includes reported downloads and cloud-saved works; offline reading still requires a downloaded EPUB. See [the implementation contract](docs/IMPLEMENTATION.md).

## Import From Calibre

Choose **Calibre Transfers** to pair Calibre with this reader library. Once paired, expand **Pairing Configuration** to view/copy credentials or revoke the pairing; it stays collapsed by default. Transfer result tabs have extra space below their buttons. Missing or blocked image references no longer prevent an otherwise readable EPUB from importing: placeholders retain available alt text, and Calibre import results note the number of unavailable images. After updating the reader, use **Failed → Retry Import** for affected transfers; remote images are never fetched. Once paired, **Check for Incoming Books** checks immediately and **Cancel Pending Imports** cancels staged imports; both controls are hidden when unpaired. In the Calibre export confirmation, choose **Download Imports** (default) or **Cloud Only** under Import Storage. Cloud Only requires an account, retains existing downloads, and makes new imports available for later download after processing. Calibre Work Link (`#work_link`) also connects recognized AO3 works to matching organizer tiles. The plugin offers **Sync Selected Books**, **Sync All Books**, and **Automatic**, **Cloud Inbox**, or **Local Reader** delivery. Automatic follows reader-cloud sign-in at pairing, independently of the organizer: account libraries use cloud delivery, guest libraries use the local bridge, and offline cloud uploads stay queued for the same account. Local delivery requires Calibre and this reader open on the same computer, with browser local-network access allowed. Both paths share EPUB parsing, duplicate skipping, in-place Calibre updates, and history preservation. Calibre’s `#work_link` column transfers automatically as **Calibre Work Link** and selects the matching EPUB for replacement while preserving reading data. You can view the saved link in **View Details**. Blank links retain the UUID/embedded-link fallback; conflicting or invalid links remain failed transfers. Plugin 1.3.0 scopes selected/all-book sync to those books; only Retry Queued Transfers processes the entire unfinished queue. Its result tabs separate Successful, Failed, Pending, and Skipped books. Use the [Calibre companion guide](../companions/calibre/README.md) to build/install the ZIP, pair, map metadata, and retry or cancel transfers. Cloud delivery requires the matching backend deployment.

Calibre imports update the existing book when its metadata or EPUB changes, using a stable Calibre identity or its AO3 work identity while preserving notes and reading history. Already-downloaded EPUBs skip file retrieval and parsing; mapped metadata still updates. Transfer results are separated into Successful, Failed, and Pending tabs. Reinstall the updated Calibre plugin to send stable identities for standalone books; the [Calibre guide](../companions/calibre/README.md) covers packaging and installation.

Reconnecting the same reader and organizer keeps one active connection and preserves queued updates and book links. New pairing codes are checked against the existing credential; a different organizer account cannot replace it silently. Other devices keep their own connections.

Account sign-in accepts your username or email and password. Password recovery requires your email address; Back to Sign In appears below Send Recovery Link. Create or change your username in Reader Account or organizer Account & Security settings; email sign-in remains available.

Continue From Organizer signs in with your existing organizer account without requiring organizer sync to be enabled. If Remember Me was unchecked in the organizer, keep that signed-in tab open while continuing. Failed handoffs show a message in Reader Account; you can also use your username or email and password.

Guest mode is for local reading only: books, notes, and progress stay on this device, with no organizer sync, availability reports, or cloud uploads. Sign in to the matching shared account to connect an organizer; one organizer belongs to one reader account, which can run on multiple devices. Pairing links received as a guest wait in this tab during sign-in, subject to the code’s five-minute expiry. Existing guest books and notes remain saved, and **Import Guest Library** explicitly copies them into an account. Old guest connections and queued organizer edits are preserved locally but no longer sent. Account downloads remain readable offline when a session expires.

## Collections

Connect your organizer account to use the same collection shelves, manual and automatic collections, appearance editors, bulk editing, reordering, and hide/show controls. Collection edits use your shared organizer library directly while online. Use Add to Collection on a linked EPUB tile to add or remove its manual memberships. The selected shelf filters the reader's saved EPUBs; shelf counts describe the shared organizer library. Collection editing requires a connected account and an online connection. Downloaded EPUBs remain readable if collection requests fail.
